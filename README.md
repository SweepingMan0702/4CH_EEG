# 4CH_EEG

這個專案是一個以 Windows 桌面應用程式形式開發的 4 通道 EEG 訊號分析系統。主要用途是從 EEG 裝置串列通訊介面讀取腦波資料，對訊號做濾波與頻譜分析，並即時視覺化展示每個通道的波形與特徵值。

## 專案目的

- 擷取 4-channel EEG 訊號
- 使用數位濾波器處理雜訊與干擾
- 進行 FFT / 頻域分析
- 計算特徵值與評分指標
- 以圖表呈現即時訊號與分析結果
- 記錄資料供後續分析或訓練資料建立

## 主要功能

- 串列通訊（COM Port）連線到 EEG 裝置
- 即時繪製 4 個通道的訊號波形
- 低通 / 高通 / 帶通濾波處理
- 頻譜分析與特徵抽取
- 眼動/異常動作偵測
- 分數評估與即時回饋介面
- 記錄原始資料與分析資料

## 技術棧

- 語言：C#
- 框架：.NET Framework 4.8
- UI：Windows Forms
- 圖表：LiveCharts
- 外觀：MaterialSkin
- 數值計算：MathNet.Numerics

## 專案結構

- `NFT_BLE(expert)/`：主要應用程式與 UI
- `Program.cs`：程式進入點
- `Signalform.cs`：EEG 訊號接收與即時分析主畫面
- `User_form.cs`：使用者操作與通訊控制
- `Filter.cs`：濾波演算法
- `feedback.cs`：回饋顯示畫面
- `packages/`：專案依賴函式庫

## 簡單說

這個專案不是一般的 Web 應用，而是一個針對 EEG 訊號的研究 / 測試工具。它把腦波資料轉成可視化圖形與數值指標，讓使用者可以觀察訊號狀態、判斷干擾或異常、並計算對應的訓練/評估分數。
